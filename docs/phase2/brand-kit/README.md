## Files

- `logo/hellofugu-logo-1024.png`, `logo/hellofugu-logo-512.png`: the FU/GU mark, square.
- `characters/*.svg` + `.png` (1024 px): the pufferfish agents. `maskot` is the mascot;
  `guardian` (health factor), `rebalancer`, `grid` and `yield` are the four DeFi kinds.
